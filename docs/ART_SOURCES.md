# Art and audio provenance

- Hotel modular meshes, room furniture, boiler controls and placeholder characters: original project-generated geometry.
- Carpet pattern and material palette: generated by the project's Editor tools, not sourced photography.
- Reference image: supplied by the user for proportions, readable silhouettes, simplified materials and friendly presentation. No source-image asset or character is included in the game.
- Fonts: Unity's bundled default font for prototype labels/UI.
- Placeholder audio: project-generated tones/noise where implemented; no third-party recordings.
- Packages: official Unity URP, Input System, Test Framework and engine modules. No paid or online-service dependencies.

This is prototype art, not a production content claim. Readability, traversal and visual hierarchy should be evaluated from both split-screen cameras.
