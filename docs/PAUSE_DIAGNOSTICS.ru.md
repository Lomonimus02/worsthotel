# Проверка зависания при Alt+Tab

Это диагностическая сборка существующей 0.3.1. Она собирает доказательства; исправление зависания и новые обращения гостей ещё не выпущены.

1. Запусти ярлык **«Запустить диагностику Alt-Tab»** в корне проекта. Он откроет отдельный SOLO и включит скрытый наблюдатель.
2. Начни игру как обычно. Переключись через **Alt+Tab**, подожди примерно **1–5 минут**, затем вернись в игру.
3. Если окно зависнет, **подожди минуту перед закрытием**: наблюдатель попробует сохранить два дампа. Затем можно закрыть зависшую игру обычным способом.
4. Сообщи, повторилось ли зависание, и сколько примерно игра была в фоне. Файлы уже останутся в проекте — вручную пересылать их не нужно.

Если короткий интервал проходит нормально, следующий полезный опыт — 10 минут вне окна и продолжение игры после возврата. Esc-пауза проверяется отдельно: это другой переход.

Каждый запуск создаёт свою папку в `docs/verification/pause`. Там сохраняются `Player.log`, журнал состояния игры, heartbeat и внешние замеры памяти/CPU. Дампы появляются только при подозрении на остановку игрового цикла; их наличие само по себе не доказывает причину зависания.

Наблюдатель работает максимум 30 минут и не закрывает игру. Для нового опыта после этого нужен новый запуск через ярлык. Закрытие игры завершает наблюдение. Сбор данных локальный; автоматической отправки файлов нет.

Обычная выпущенная сборка остаётся в `Builds/Windows-0.3.1`. Диагностическая — в `Builds/Windows-0.3.2-pause-diagnostic`; запуск непосредственно её EXE без ярлыка не включает сбор данных.

Для разработчика: [расследование и реальные результаты](PAUSE_CRASH_INVESTIGATION.md), [задание 0.3.2](NATURAL_SERVICE_REQUEST.txt).
